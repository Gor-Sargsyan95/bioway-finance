# BioWay Finance

Веб-приложение для учёта затрат и прибыли BioWay Beauty Club (3 партнёра).

## Возможности
- Регистрация / вход для каждого партнёра
- Добавление затрат (билеты, подарки, еда, продукты и материалы и др.) и продаж
- Поля: сумма, дата, категория, продукт, количество, клиент, комментарий
- Загрузка квитанций (фото/пдф)
- Общая прибыль = продажи - затраты (без деления)
- Синхронизация на всех устройствах

## Настройка (5 минут)

1. Создайте бесплатный аккаунт на https://supabase.com
2. Создайте новый проект (Project)
3. В SQL Editor выполните:

```sql
create table entries (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users,
  user_email text,
  type text check (type in ('expense', 'sale')),
  amount numeric not null,
  date date not null,
  category text,
  product text,
  quantity integer,
  client text,
  description text,
  receipt_path text,
  created_at timestamptz default now()
);

-- Разрешить всем аутентифицированным читать и писать
alter table entries enable row level security;
create policy "Allow all for authenticated" on entries for all to authenticated using (true) with check (true);

-- Storage для квитанций
insert into storage.buckets (id, name, public) values ('receipts', 'receipts', false);
create policy "Allow authenticated uploads" on storage.objects for all to authenticated using (bucket_id = 'receipts');
```

4. Скопируйте Project URL и anon public key (Settings → API)
5. Замените в index.html строки:
   ```js
   const SUPABASE_URL = 'https://xxxx.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJ...';
   ```
6. Закоммитьте изменения в GitHub
7. В Netlify (bioway-finance) подключите репозиторий GitHub для авто-деплоя

После этого приложение будет доступно по адресу https://bioway-finance.netlify.app

Каждый партнёр регистрируется со своим email и может добавлять данные с любого устройства.
